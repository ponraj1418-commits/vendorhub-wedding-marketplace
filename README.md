# VendorHub – Wedding Vendor Marketplace

**Internship Task:** WD-MAT-005  
**Student Code:** DAS-MAT-005  
**Domain:** Wedding Vendor Marketplace

## Project
VendorHub is a responsive frontend marketplace for discovering, comparing and booking wedding vendors.

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Fonts
- Unsplash image URLs

## Features
- Vendor search
- Category, price and rating filters
- Vendor profiles
- Services and pricing
- Booking simulation
- Booking confirmation
- Favorites/wishlist
- User dashboard
- Demo login
- Responsive design
- LocalStorage persistence
- Mobile navigation

## Run
Download the project and open `index.html` in a browser. No server or database is required.

## GitHub Pages
After uploading the files to a public GitHub repository:
1. Open Settings → Pages.
2. Select the main branch and root folder.
3. Save and wait for the Pages URL.
